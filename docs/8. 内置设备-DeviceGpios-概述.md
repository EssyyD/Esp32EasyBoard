# 8. 内置设备 DeviceGpios - 概述

GPIO 设备继承 `DeviceGpioBase<Derived>`（CRTP 模板基类）。

基类 boot 时自动遍历 `PIN_GPIOS` 向 EasyBoard 注册所有引脚：

```cpp
template<typename Derived>
bool DeviceGpioBase<Derived>::boot(const char* serviceName) {
    if (!DeviceBase::boot(serviceName)) return false;
    auto* derived = static_cast<Derived*>(this);
    for (auto& pin : derived->PIN_GPIOS)
        this->bootEASYB->bootGPIO(pin.pin, pin.owner);
    return true;
}
```

`pinMode`、`digitalWrite`、中断挂载等操作在子类的 `boot()` 中自行完成。

GPIO 设备需要在 `EasyBoard::onboardDeviceGpio()` 中调用 `setEasyBoard(this)` 注入 EasyBoard 指针，否则 `bootEASYB` 为空。

## 新增 GPIO 设备

1. 在 `config/pinGpios.config.h` 定义引脚宏
2. 写头文件：继承 `DeviceGpioBase<Derived>`，声明 `PINS`（含 `begin()`/`end()`）
3. 写实现文件：第一行 `#include "core/base/DeviceBase.gpio.cpp"`
4. 在 `EasyBoard.h` 的 `devicesGpio` struct 中挂载
5. 在 `EasyBoard::onboardDeviceGpio()` 中 `setEasyBoard(this)`

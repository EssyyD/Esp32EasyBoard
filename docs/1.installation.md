# 1. 安装

## 1.1 前置条件

- [PlatformIO](https://platformio.org/install) 已安装（VS Code 扩展或命令行均可）
- ESP32 USB 驱动已就绪（Windows 下通常需要 [CP210x 驱动](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)，macOS/Linux 免驱）

## 1.2 获取项目

```bash
git clone https://github.com/EssyyD/Esp32EasyBoard.git
cd Esp32EasyBoard
```

## 1.3 安装依赖

框架依赖在 `platformio.ini` 中声明，首次编译会自动下载：

```bash
pio run
```

首次运行会比较久——PlatformIO 会拉取 espressif32 工具链（~200MB）和所有 lib_deps 依赖。之后再编译只会处理本项目源文件。

## 1.4 验证

编译通过且无报错即表示环境和依赖就绪。此时固件还未烧录到芯片，下一步见「开始使用」。

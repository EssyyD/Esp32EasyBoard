# 5. EasyBoard板级中枢

`EasyBoard` 是框架唯一的中央单例，它持有所有总线、设备实例和服务实例。

**使用方法**：include 头文件后，即可通过宏或静态方法获取实例：

```cpp
#include "core/EasyBoard.h"

EASYB                   // 推荐：简短宏，全局可用
EasyBoard::instance()   // 等价写法
```

## 5.1 初始化流程

```cpp
void EasyBoard::init() {
    delay(800);                          // 等待芯片稳定
    Serial.begin(115200);               // USB HW-CDC
    LittleFS.begin(false);              // 文件系统（不自动格式化）
    this->bootGPIO(PIN_GPIO_LED_BUILTIN, "NeoPixel");
    this->neoPixel.begin();             // 板载 WS2812
    this->initI2c();                    // Wire.begin（若引脚非 NC）
    this->initSpi();                    // new SPIClass（若引脚非 NC）
    this->onboardDeviceGpio();          // 给 GPIO 设备注入 EasyBoard 指针
}
```

## 5.2 设备与服务容器

EasyBoard 通过匿名 struct 持有所有设备和服务的实例，经宏 `EASYB` 全局访问：

### 设备（按总线分组）

```cpp
// GPIO 设备 —— 指针，经 instance() 工厂创建
EASYB.devicesGpio.mic           // MicInmp441GpioDevice*
EASYB.devicesGpio.spk           // SpkMax98357GpioDevice*
EASYB.devicesGpio.tb6612Wheels  // DriverMotorTb6612Device*

// I2C 设备
EASYB.devicesI2c.oledSsd13065   // OledSsd1306I2cDevice*

// SPI 设备
EASYB.devicesSpi.lcdNv3007      // LcdNv3007Device*
EASYB.devicesSpi.lcdNv3007_2    // LcdNv3007Device* (副屏)

// 其他
EASYB.wifi                      // WifiEsp32S3Device
```

### 服务（值成员，直接 `.rtosRun()` 启动）

```cpp
EASYB.servicesRtos.voiceEchoServiceRtos
EASYB.servicesRtos.connectivityServiceRtos
EASYB.servicesRtos.motionServiceRtos
EASYB.servicesRtos.displayServiceRtos
```

### 其他组件

```cpp
EASYB.chipWebServerRtos   // Web 服务（由 WiFi 状态自动启停）
EASYB.chipSqlite          // SQLite（需手动 boot）
EASYB.neoPixel            // Adafruit_NeoPixel 实例
```

## 5.3 总线

框架持有全部硬件总线实例，设备通过 EasyBoard 获取总线指针。

### SPI

```cpp
SPIClass* spiH = nullptr;  // HSPI，initSpi() 中 new + begin
SPIClass* spiF = nullptr;  // FSPI，同上
```

`new SPIClass` **只在这里调用**。设备通过 `EASYB.spiH` / `EASYB.spiF` 获取指针。引脚为 `GPIO_NUM_NC` 时对应的 SPI 不初始化，指针保持 `nullptr`。

### I2C

```cpp
TwoWire* i2c0 = &Wire;  // initI2c() 中 Wire.begin(SDA, SCL) @400kHz
```

`Wire.begin()` **只在这里调用一次**。设备通过 `EASYB.i2c0` 获取指针。

### 软件 I2C

如果外设需要额外的 I2C 总线（不走硬件 I2C0），可通过 `I2cSoftBase` 实现软件模拟 I2C。实例挂在 `EASYB.i2cSofts` 结构体中。

## 5.4 GPIO 引脚管理

```cpp
bool bootGPIO(gpio_num_t pin, const char* owner);  // 注册占用
void unbootGPIO(gpio_num_t pin);                    // 释放占用
void dumpPins();                                     // 打印占用表
```

所有引脚占用需经此注册表（容量 32）。`GPIO_NUM_NC` 自动放行。重复占用会打 `[GPIO] CONFLICT` 日志，但不阻止运行——这是自检机制而非硬保护。启动日志中会输出 `=== GPIO Allocations ===` 完整占用清单。

EASYB.setLed(r, g, b);  // 0~255

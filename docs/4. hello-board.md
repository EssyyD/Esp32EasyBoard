# 4. Hello Board

这是一个最小可运行示例，用于验证工具链和开发板是否就绪。

## 4.1 代码

将 `src/main.cpp` 替换为以下内容：

```cpp
#include <Arduino.h>
#include "core/EasyBoard.h"

void setup() {
    EASYB.init();

    // 点亮板载 NeoPixel：绿色
    EASYB.setLed(0, 255, 0);

    Serial.println("[main] Hello Esp32EasyBoard!");
}

void loop() {
    vTaskDelay(portMAX_DELAY);
}
```

## 4.2 效果

编译烧录后，打开串口监视器（115200bps）：

```
[EasyBoard] Wire.begin(SDA=41, SCL=42)
[EasyBoard] HSPI begin(SCK=2, MOSI=1)
=== GPIO Allocations ===
  GPIO 48 -> NeoPixel
[main] Hello Esp32EasyBoard!
```

板载 LED 亮起绿色。

## 4.3 逐行说明

| 行 | 说明 |
|---|---|
| `EASYB.init()` | 初始化串口、LittleFS、I2C、SPI、NeoPixel 和所有已声明设备 |
| `EASYB.setLed(0, 255, 0)` | 板载 WS2812 LED 设为绿色（RGB 0~255） |
| `vTaskDelay(portMAX_DELAY)` | 让 Arduino `loop()` 永久阻塞——后续业务逻辑推荐写成服务（见 `docs/2.architecture.md`） |

## 4.4 下一步

这个范例没有用到任何外设或服务，只是验证环境。实际开发中推荐启动预置服务来驱动硬件，或按架构章节的模式编写自己的设备和服务。

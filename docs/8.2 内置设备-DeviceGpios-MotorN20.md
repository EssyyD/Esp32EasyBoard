# 8.2 DeviceGpios - MotorN20

N20 编码器直流电机，多实例（`_MULTI_INSTANCE = true`）。

**源文件**：`src/device/gpio/Motor.N20.gpio.device.{h,cpp}`

**挂载点**：不直接挂在 EasyBoard，而是挂在 TB6612 的 `motors.motor1` / `motors.motor2`。

## 引脚

编码器 A/B 相（如 `PIN_GPIO_MOTOR_N20_WHEEL_1_ENC_A` / `_B`）。动力引脚通过 `setDriver()` 绑定 TB6612 后由后者代为控制。

## API

| 方法 | 说明 |
|---|---|
| `setSpeed(int s)` | 速度 0~100，内部 `map(s, 0, 100, 0, 255)` |
| `forward()` | IN1=HIGH, IN2=LOW, PWM=map(speed) |
| `backward()` | IN1=LOW, IN2=HIGH, PWM=map(speed) |
| `brake()` | IN1=LOW, IN2=LOW, PWM=0 |
| `coast()` | IN1=HIGH, IN2=HIGH, PWM=0 |
| `getPosition()` | 读取编码器累计位置 |
| `resetPosition()` | 位置归零 |
| `setDriver(d, ch, in1, in2)` | 绑定电机驱动芯片 |

未挂 driver 时所有动作方法 no-op。

## 编码器

boot 时在 A 相挂 `attachInterruptArg(CHANGE)`，ISR（IRAM_ATTR）按 B 相电平 `position++/--`。unboot 时 `detachInterrupt`。

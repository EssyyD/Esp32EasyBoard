# 8.1 DeviceGpios - DriverMotorTb6612

TB6612FNG 双路直流电机驱动，单例（`_MULTI_INSTANCE = false`）。

**源文件**：`src/device/gpio/DriverMotor.Tb6612.gpio.device.{h,cpp}`

**挂载点**：`EASYB.devicesGpio.tb6612Wheels`

## 引脚

motor1（必接）和 motor2（可选，引脚为 NC 时跳过）各含 PWM + IN1 + IN2，外加 STBY 使能脚。当前 Wheels 组全部为 `GPIO_NUM_NC`。

## API

| 方法 | 说明 |
|---|---|
| `standby()` | 拉低 STBY，双电机全部停转 |

## 电机挂载

```cpp
struct { MotorN20Device* motor1 = nullptr; MotorN20Device* motor2 = nullptr; } motors;
```

挂载发生在 `EasyBoard::onboardDeviceGpio()`。boot 时自动级联：`motor->setEasyBoard → boot → setDriver(this, ch, in1, in2)`。

## 硬件资源

- **LEDC ch0 / ch1**（20kHz, 8bit），boot 时配置，unboot 时释放
- STBY 拉低时双电机停转但不释放 PWM
